# Changelog

## v0.1.0 — Core Radio Engine

Initial LocalRadio release.

- Added incremental local music library scanning.
- Added persistent SQLite catalog and play history.
- Added central one-station playout engine.
- Added song and artist repeat protection with graceful fallback for small libraries.
- Added FFmpeg real-time MP3 transcoding and live stream fan-out.
- Added IPTV M3U output.
- Added responsive status dashboard and library scan control.
- Added health/status/catalog APIs.
- Added Docker, CasaOS and GHCR multi-architecture deployment files.
- Added PUID/PGID support and read-only music-library mapping.
